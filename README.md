# Rosangela Silvestre | Hipnoterapeuta Clínica

Site institucional de página única de Rosangela Lucia Silvestre, hipnoterapeuta clínica em Cariacica, ES.

## Estrutura

- `index.html`: o site inteiro (HTML, CSS e JavaScript no mesmo arquivo; fotos embutidas).
- `og-image.jpg`: imagem de compartilhamento (WhatsApp, Instagram, Facebook).
- `assets/`: vídeos de depoimento e suas capas.

## Como publicar

Envie todos os arquivos mantendo a estrutura de pastas para a raiz da hospedagem (por exemplo, `public_html`). Não há etapa de build.

## Pendências

- Domínio: o site usa https://institucionalrosangelasilvestre.vercel.app/. Se trocar de domínio, atualize esse endereço nas tags de compartilhamento, no link canônico e no JSON-LD do `index.html`.
- Nome da segunda paciente nos depoimentos, se autorizado.

## Contato

O número do WhatsApp fica numa única constante (`WHATSAPP`) no final do `index.html`.
